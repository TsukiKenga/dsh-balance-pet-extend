# 与 Windows 版的功能对照（v1.9.0）

检查对象：[VK-1 / windows / dsh_pet.ps1](https://github.com/VKmich16/VK-1/blob/main/windows/dsh_pet.ps1)
（Windows v3 开发版，PowerShell 5.1 + 内嵌 C# WinForms）。

本插件 v1.9.0 的目标不是「把桌面窗口搬进网页」，而是把**网页形态能表达**的玩法补齐。
下面逐项列出结论；「未补全」的每一项都写明了原因，不是遗漏。

## 一、已补全

| Windows 功能 | 本插件实现 | 备注 |
| --- | --- | --- |
| 自定义扣费步长（每扣多少钱提示一次） | 右键「扣费步长」：0.01 / 0.05 / 0.10 / 0.50 / 1.00 + 自定义 0.01 ~ 100 元 | 内部用万分之一元整数记账；显示与步长都回到 0.01 精度；不足一步按实际差额补最后一拍 |
| 每个音效独立音量 | 「声音 → 单独音效」6 个槽各自 0–100 % | 受击 / 投喂 / 扣头 / 取锅 / 回合结束 / 结算 |
| 自定义音效 | 每个槽可上传一个音频；格式过滤 + `canPlayType` 复核 + IndexedDB 持久化 + 试听 + 恢复出厂 | 支持 mp3 / wav / ogg / m4a / aac / flac / webm / opus，上限 20 MB；不做 Windows 的裁剪 / 增益 / 多文件库 |
| 平板「梁文峰 / 梁文谷 + 剩余时长」 | 单击平板切换；仅 DSH 账户余额 / DeepSeek | 用插件自己的峰谷口径（9–12 / 14–18，周末与节假日谷价），不含「今日已用」 |
| 功能开关：充值掉盆 | 「功能选择」开关 | 关掉后充值直接入账 |
| 功能开关：摸头 | 「功能选择」开关 | 关掉后不再识别划动 |
| 功能开关：扣费音效与动画 | 「功能选择」开关 | 关掉后余额仍变，但不红闪 / 不震动 / 不飘字 / 不响 |
| 摸头（petpet） | 指针在她身上划动 24 px + 持续 0.5 秒 → 5 帧手部动画 + 开心表情 + 爱心 | 手部素材逐字节取自 VK-1 `windows/sprites/pat_hand_*.png` |
| 铁锅堆叠 | 每吃掉一个米饭盆掉一个锅，最多 5 个，间距 2/3 锅高 | 与上游 `IronStackGap` 同值 |
| 铁锅只在下落时扣头 | 下落速度 ≥ 30 px/s 才吸附 | 与上游 `IronSeatMinFallSpeed` 同值 |
| 双击头部取锅 | 只取**最上面**一个，下面的自动补位 | 与上游「一次取一个」一致 |
| 铁锅落头 / 取下音效 | `pot_land.mp3` / `pot_off.mp3` | 逐字节取自 VK-1 `windows/` |
| 左下 / 右下角吸附 | 松手时按屏幕左右半边选择；菜单可固定或关闭 | 受网页限制，只能吸附**浏览器窗口**的角 |
| 零余额冷脸 | 余额 ≤ 0.005 元时切「傲娇」表情 | 上游 v3 用表情替代死亡 / 重生动画 |
| 测试充值金额 | 「测试充值 → 自定义金额…」 | 默认 3 元；关掉掉盆时只演示光环与飘字 |
| 自定义演示次数 | 「演示连续扣费 → 自定义次数…」 | 1 ~ 200 次 |
| 立即刷新 | 菜单「立即刷新余额」 | 手动刷新也走扣费动画，方便核对步长 |
| 表情优先级 | 摸头 > 零余额 > 铁锅 > 扣费 > 盆超时 > 常态 | 与上游 v3 的 `UpdateExpression` 对齐 |
| 状态持久化 | `localStorage` + IndexedDB | 步长 / 开关 / 左右角 / 尺寸 / 音量 / 自定义音效 / 主题 / 位置 |

## 二、未补全（以及原因）

| Windows 功能 | 状态 | 原因 |
| --- | --- | --- |
| 系统托盘图标 / 双击托盘扣费 | ❌ | 网页没有系统托盘；本插件用右键菜单与全局热键替代 |
| 原生置顶、跨应用透明穿透、吸附操作系统屏幕角 | ❌ | 桌面壳能力；网页只能作用于 DSH 页面与浏览器窗口 |
| 读写 `apikey.txt` / `state.ini` | ❌ | 改用 DSH 凭据服务与 `localStorage`；不再需要用户填 key |
| 自定义音效的裁剪 / 增益 / 多文件库 | ❌ | 本版每个槽一个自定义文件 + 音量 + 试听；编辑波形需要额外 UI 与解码链路 |
| 平板「今日已用 / 校准今日已用」 | ❌ | 本插件把「本轮 / 累计消耗」放在喜报与累计计费里；平板彩蛋只显示峰谷状态与剩余时长 |
| Windows 完整系统代理探测 | 部分 | 宿主已有「网络自检」与 `HTTPS_PROXY` 提示；网页端无法读取系统代理设置 |

## 三、验证方式

```powershell
node test/smoke.mjs
```

在最小 DOM / Canvas / 虚拟时钟里真跑 `assets/pet.js`，当前 **153 项全绿**，其中新增覆盖：

- 6 个音效的独立音量：菜单结构、受击 25% 时实际播放音量
- 平板峰谷彩蛋：标题「DSH 账户余额」、点击切「梁文峰」、剩余时长、再点切回
- 步长五档预设、自定义 0 / 小于 0.01 被拒绝 / 0.02、连续演示逐拍飘字、真实 0.30 按 0.10 拆成 3 拍
- 三个功能开关的勾选与效果（不飘字 / 不响 / 不掉盆）
- 左右下角吸附与「关闭」状态
- 摸头手部素材、开心表情、指针离开后收起
- 铁锅堆叠与连续双击取锅
- 零余额冷脸
- 自定义演示次数 / 测试充值金额的校验与生效

宿主侧新增路由（`/tariff.json`、`/pat/*`、`/sound/pot_*.mp3`）**需要重启 DSH** 后才会注册；
只刷新页面时，新浏览器脚本可以立刻工作，但峰谷状态、手部素材与锅音效会 404。
