# 与 Windows 版的功能对照（v1.8.0）

检查对象：[VK-1 / windows / dsh_pet.ps1](https://github.com/VKmich16/VK-1/blob/main/windows/dsh_pet.ps1)
（Windows v3 开发版，PowerShell 5.1 + 内嵌 C# WinForms）。

本插件 v1.8.0 的目标不是「把桌面窗口搬进网页」，而是把**网页形态能表达**的玩法补齐。
下面逐项列出结论；「未补全」的每一项都写明了原因，不是遗漏。
（版本号固定在 1.8.0，后续改动直接并入本版，不再升级。）

## 一、已补全

| Windows 功能 | 本插件实现 | 备注 |
| --- | --- | --- |
| 自定义扣费步长（每扣多少钱提示一次） | 右键「扣费步长」：0.01 / 0.05 / 0.10 / 0.50 / 1.00 + 自定义 0.01 ~ 100 元 | 内部用万分之一元整数记账；显示与步长都回到 0.01 精度；不足一步按实际差额补最后一拍 |
| 每个音效独立音量 | 右键「声音」先选模式：勾选「分音效调节音量」→「单独音效」6 个槽各自 0–100 %；不勾选 → 只显示「全部音效音量」 | 两种音量视图互斥；**不勾选时「单独音效（自定义音频）」栏仍然显示**（只保留试听 / 上传 / 恢复出厂，不再有音量档位） |
| 自定义音效 | 每个槽可上传一个音频；格式过滤 + `canPlayType` 复核 + IndexedDB 持久化 + 试听 + **剪取片段（起点/终点 → WAV）** + 恢复出厂 | 支持 mp3 / wav / ogg / m4a / aac / flac / webm / opus，上限 20 MB；不做 Windows 的增益 / 多文件库 |
| 平板「梁文峰 / 梁文谷 + 剩余时长」 | 单击平板显示 **2.5 秒（可在「平板峰谷时长」里改，0.5 ~ 60 秒）**；**两行**（第一行 梁文峰 / 梁文谷，第二行 距峰时 / 距谷时 + 倒计时）；峰价红底、谷价绿底；不显示余额；仅 DSH 账户余额 / DeepSeek | 用插件自己的峰谷口径（9–12 / 14–18，周末与节假日谷价），不含「今日已用」 |
| 火控雷达 | 菜单「打开火控雷达」提前显示名牌，并把**自动拾取缩短到 3 秒**（落地稳定满 3 秒立即以最高速吸走，不再额外等 1 秒）；关闭后恢复 10 秒 + 1 秒流程 | 名牌几何、读数与方向环照抄上游；吸附修正为「直接朝她推进」，不会绕圈 |
| 摸头（petpet） | 指针在她身上划动 24 px + 持续 0.5 秒 → 5 帧手部动画 + **`expression_22`** + 爱心 + **petpet 弹性形变**（横向 0.80+j×0.02、竖向 0.80-j×0.05、offsetY 下沉） | 手部素材与形变参数逐字节 / 逐条取自 VK-1；上游 `UpdateExpression` 摸头就是 `EXPR_NERVOUS` |
| 铁锅扣头 / 取下的回弹 | 竖直压缩-拉伸 0.5 秒：`cos(u·2.2π)·(1-u)·0.16`，锚点在脚底；头上的锅与平板读数一起弹 | 与上游 `HeadSquashDur / _headSquashT` 同一公式 |
| 右侧镜像 | 拖过屏幕中线（或吸附到右侧）时整只镜像：立绘 `scale(-1,1)`、平板四边形按「原图宽度 - x」反射、摸头的手一起翻；平板文字保持正向 | 上游 `_snapRight / SyncSideToPosition / UpdateMirrorGeometry`；镜像后仍可点平板 |
| 功能开关：充值掉盆 | 「功能选择」开关 | 关掉后充值直接入账 |
| 功能开关：摸头 | 「功能选择」开关 | 关掉后不再识别划动 |
| 功能开关：扣费音效与动画 | 「功能选择」开关 | 关掉后余额仍变，但不红闪 / 不震动 / 不飘字 / 不响 |
| 铁锅堆叠 | 每吃掉一个米饭盆掉一个锅，最多 5 个；按**可见锅体**高度算间距（不是整张方图）；头上的锅大小跟随尺寸档 | 与上游 `IronStackGap` 的观感对齐 |
| 头上的锅是碰撞体积 | 从上方松手落下的米饭盆会撞在锅沿上被横向弹开（AABB 近似可见锅体：半宽 0.86r、半高 0.347r），不会穿过锅落到她头上 | 新增行为；铁锅之间仍按原有堆叠 / 扣头判定 |
| 拖拽米饭盆的流体形变 | 有饭的米饭盆位置跟手，但像装了半碗水的软体：横向拖动时下半部分被甩在后面（剪切，刚度 150 / 阻尼 10），同时横向拉宽、竖向压扁（刚度 200 / 阻尼 13）；停手后形变来回晃几下再回正；空铁锅保持精确跟手 | 强度可调：「拖盆流体效果」默认**强 1.6×**（实际约 0.67r / 32%），可选 关闭 / 0.7× / 1× / 1.6× / 2.4× 或自定义 0~2.5× |
| 空锅落地 / 二次拖回扣头 | 空锅先从桌宠抛到窗口底部随机位置，落地播放扣头音效；第二次拖回她身上才扣头 | 按用户要求实现，不自动扣头 |
| 双击头部取锅 | 只取**最上面**一个，下面的自动补位 | 与上游「一次取一个」一致 |
| 铁锅落头 / 取下音效 | 已对调：扣头 `pot_off.mp3`，取下 `pot_land.mp3` | 逐字节取自 VK-1 `windows/` |
| 左下 / 右下角吸附 | 松手时按屏幕左右半边选择；菜单可固定或关闭 | 受网页限制，只能吸附**浏览器窗口**的角 |
| 零余额冷脸 | 余额 ≤ 0.005 元时切「傲娇」表情 | 上游 v3 用表情替代死亡 / 重生动画 |
| 测试充值（盆数） | 「测试充值」→ 掉 1 / 3 / 10 盆饭；另有「自定义金额…（掉 1 盆）」 | 关掉掉盆时只演示光环与飘字 |
| 自定义演示次数 | 「演示连续扣费 → 自定义次数…」 | 1 ~ 200 次 |
| 立即刷新 | 菜单「立即刷新余额」 | 手动刷新也走扣费动画，方便核对步长 |
| 表情优先级 | 摸头 > 零余额 > 铁锅 > 扣费 > 盆超时 > 常态 | 与上游 v3 的 `UpdateExpression` 对齐 |
| 状态持久化 | `localStorage` + IndexedDB | 步长 / 开关 / 左右角 / 尺寸 / 音量 / 自定义音效 / 主题 / 位置 |
| 余额来源拆分 | 内置「DSH 账户余额」只走账号登录态；手动 `DEEPSEEK_API_KEY` 独立成「DeepSeek（手动 Key）」，两条来源分开缓存 / 显示 / 自检 | 新增行为（上游没有手动 key 与账号余额并存的概念） |
| 未收录模型 token | 价目表与自定义单价都没匹配上的模型，仍按默认价记账，并记录实际 token；结算页标「（未收录）」+ 合计 | 新增行为；账本落盘 `modelTokens` / `unknownTokens` / `unknownModels` |
| 手动模型价格表 | 右键「模型价格表」：导入 JSON（按 id / matchIds 合并，同 id 即更新）/ 编辑当前表 / 清空；落盘 `.dshpet-prices.json`，优先于 `.dshw-api.json` 与内置价目表 | 新增行为；单位元/百万 token，支持 USD + rate |
| 白饭落地音效 | 米饭盆落到窗口底部时播放与铁锅落地相同的 `land` 音效（每个盆只响一次） | 新增行为；铁锅逻辑不变 |
| 手动 Key 余额不串账户 | 手动 Key 来源始终列出（未配时标「未配置」）；切换来源时丢弃上一来源在飞的请求 | 修复「手动 Key 余额偶发与 DSH 账户余额一致」 |

## 二、未补全（以及原因）

| Windows 功能 | 状态 | 原因 |
| --- | --- | --- |
| 系统托盘图标 / 双击托盘扣费 | ❌ | 网页没有系统托盘；本插件用右键菜单与全局热键替代 |
| 原生置顶、跨应用透明穿透、吸附操作系统屏幕角 | ❌ | 桌面壳能力；网页只能作用于 DSH 页面与浏览器窗口 |
| 读写 `apikey.txt` / `state.ini` | ❌ | 改用 DSH 凭据服务与 `localStorage`；不再需要用户填 key |
| 自定义音效的增益 / 多文件库 | ❌ | 本版每个槽一个自定义文件 + 音量 + 试听 + 片段裁剪；编辑波形 / 增益需要额外 UI 与解码链路 |
| 平板「今日已用 / 校准今日已用」 | ❌ | 本插件把「本轮 / 累计消耗」放在喜报与累计计费里；平板彩蛋只显示峰谷状态与剩余时长 |
| Windows 完整系统代理探测 | 部分 | 宿主已有「网络自检」与 `HTTPS_PROXY` 提示；网页端无法读取系统代理设置 |

## 三、验证方式

```powershell
node test/smoke.mjs
```

在最小 DOM / Canvas / 虚拟时钟里真跑 `assets/pet.js`，当前 **221 项全绿**（另有 `test/pricing.mjs` 22 项计价 / 价格表校验），其中新增覆盖：

- 声音两种模式互斥显示；**不勾选分音效时自定义音频栏仍然显示**（子菜单只剩试听 / 上传 / 恢复出厂）；6 个音效独立音量、受击 25% 时实际播放音量
- 平板峰谷彩蛋：标题「DSH 账户余额」、点击显示「梁文峰」、**两行布局（无「峰谷时段」标题）**、红色背景、剩余时长、**默认 2.5 秒 / 自定义 1.5 秒后回余额**
- 步长五档预设、自定义 0 / 小于 0.01 被拒绝 / 0.02、连续演示逐拍飘字、真实 0.30 按 0.10 拆成 3 拍
- 三个功能开关的勾选与效果（不飘字 / 不响 / 不掉盆）
- 左右下角吸附与「关闭」状态；**右侧镜像**（立绘 `scale(-1,1)`、平板仿射 `c` 变负、镜像后仍能点平板）
- 摸头手部素材、**`expression_22`**、**petpet 弹性形变**、指针离开后收起
- 铁锅：空锅先落地（不自动扣头）、第二次拖回她身上才扣头；**扣头竖直回弹形变**；扣头 / 取下音效对调；连续双击取锅
- **头上有锅时的碰撞体积**：把桌宠移到下落中的米饭盆下方，盆撞到锅沿后被横向弹开
- **拖拽米饭盆的流体形变**：拖动时碗跟手，出现横向拉伸 + 竖向压扁 + 下半部分剪切，停手后回正
- **拖盆流体强度**：默认 1.6×、五档预设、自定义 2× 生效、3× 被拒绝、关闭后拖动无形变
- **测试充值盆数**：「掉 1 / 3 / 10 盆饭」分别生成 1 / 3 / 10 个米饭盆
- **火控雷达开启后自动拾取缩短**（3 秒阈值；关闭后恢复 10 秒流程）
- **未收录模型 token**：结算页显示「（未收录）」+ 千分位 token 与未收录合计
- **模型价格表**：菜单条数、编辑 JSON 保存、保存后条数更新；宿主校验 / 合并（22 项计价）
- **白饭落地音效**：米饭盆落到窗口底部会播放铁盆落地音
- 零余额冷脸
- 自定义演示次数 / 测试充值金额的校验与生效

宿主侧新增路由（`/tariff.json`、`/pat/*`、`/sound/pot_*.mp3`）**需要重启 DSH** 后才会注册；
只刷新页面时，新浏览器脚本可以立刻工作，但峰谷状态、手部素材与锅音效会 404。
