DSH-DaFeiYu-Desktop-Pet                     ← fork 自 VK-1 的 Mac 分支
--------------------------------------------------------------------------
  仓库      https://github.com/Andromedahk/DSH-DaFeiYu-Desktop-Pet
  作者      Andromedahk
  许可      上游未另行授予许可
            （VK-1 的 MIT 不覆盖此目录，VK-1 README 写明「许可以其独立说明为准」）

  与 VK-1 的关系：fork 自 https://github.com/VKmich16/VK-1，做的是 macOS 原生版
  （Swift + AppKit），后来被上游合并（VK-1 的 PR #1）。

  本插件的用途：本插件就是基于这一版改写的 —— 四个角色、立绘、平板布局、
  扣费动画与「抱盆」离线态都来自这里。assets/sprites/ 下的 5 张立绘
  （fish / fish-offline / gpt / claude / gemini）与这一版逐字节相同。

  ⚠ 重要 —— 打包发布前必须留意

  该仓库的 Resources/README.md 明确写着：

    「上游原作者说明 UI 图片由其处理；上游暂未附许可证。这里保留来源说明，
      不另行授予上游代码、素材或衍生图片的许可。」

  而且它的四张角色立绘是在 Windows 原图（1024x1024）基础上 AI 补全出来的
  1536x1024 版本，该说明也写明「含轻微生成重绘，不能视作原图逐像素不变的扩边」。

  也就是说：assets/sprites/ 下的 5 张立绘没有明确的可再分发依据。本插件按 as-is
  随包提供、仅供本地运行。如果要公开发布这个插件，建议先向 Andromedahk 与
  VKmich 确认授权，或替换成你自己拥有权利的立绘。
