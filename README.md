# DSH余额桌宠 · DSH Balance Pet Enhanced
>「本项目基于 [VKmich16/VK-1](https://www.github.com/VKmich16/VK-1) 二次开发

贴在 **DSH** 页面里的余额桌宠：角色举着一块倾斜的平板，实时显示你的余额。

余额每**下降 0.01 元**，她红闪 + 震动 + 播放打击音效，头顶飘出 `-0.01`，0.2 秒一次串成一条；
余额**上升（充值）**时，掉下一盆米饭，把它**拖到角色身上**才一次性入账。

| | |
| --- | --- |
| **当前版本** | **v1.7.0** |
| **技术栈** | 宿主侧 Node（余额轮询 / 计价）+ 浏览器侧单文件 IIFE（Canvas 绘制 / 交互） |
| **依赖** | 无。只读 DSH 自己的凭据，不联网上传任何数据 |

与 [`dsh-whale-widget`](https://github.com/MeteorNOX/DeepSeek-Balance-Whale-Widget) **互不依赖，可以共存**：
鲸鱼挂件固定在右下角，本桌宠默认吸附**左下角**。

## 🍚 米饭盆充值玩法

余额**上涨**时会掉下一盆米饭。这一套玩法移植自上游 VK-1 v2。

### 1. 拖动投喂

左键**按住盆拖动**，拖到角色身上才入账（碰到头发 / 头饰也算）→ 盆消失、头顶冒像素爱心、
这笔充值一次性加到屏幕上。也可以把盆**甩出去**。

> 不拖就永远不加 —— 盆可以一直躺在窗口底部。所以你想什么时候「收钱」都行。

### 2. 多盆并存

一笔充值掉一个盆，**场上可以同时有好几个**。盆彼此有**碰撞体积**，落点会错开，不会叠成一堆。

### 3. 火控雷达：目标名牌

盆被锁定时，周围会出现一个《战争雷霆》风格的**绿色方括号 + 一排读数**：

| 读数 | 含义 |
| --- | --- |
| **类型** | `白饭` |
| **距离** | 盆离她多远（单位 **kpx**） |
| **接近率** | 盆在靠近（正数）还是远离（负数），单位 `px/s` |
| **相对高度** | 正数 = 盆比她高，负数 = 比它低，单位 `px` |
| **方向环** | 名牌下方一个圆环，环上一根指针指向盆相对她的**方位** |

> ⚠️ **米饭盆落地后 10 秒还没喂她，就会被锁定；再过 1 秒开始被吸走吃掉。**
> 如果一次充了好几笔、掉了一地盆：**只要有一个满 10 秒，所有的盆会一起被锁定、一起吸走。**

想提前看看名牌长什么样（不喂也不会被吸）：右键 →「测试充值（掉米饭盆）」→「打开火控雷达」。
它只把名牌提前亮出来，**不会**缩短倒计时、也不会启动吸附。

### 4. 铁锅：米饭盆的「后事」

米饭盆被她**吃掉**的地方，会掉出一个**铁锅**：

- 铁锅不值钱、也不能吃，纯玩具，**照样能拖**
- **拖到她头顶**（或者干脆扔到她头顶），它就会扣在她头上 → 她变冷脸，还会顶着锅一起抖
- **双击她的头** → 它渐隐消失
- 同时只会有一个，不会越堆越多；它**永远不会**被火控雷达锁定

## 😄 表情差分

四张脸，按当前状态自动切换。优先级从高到低，**第一个命中的生效**：

| 优先级 | 条件 | 表情 |
| --- | --- | --- |
| 1 | 铁锅扣在头上 **且** 场上没有活的米饭盆 | 😐 **冷脸**（`expression_21`） |
| 2 | 正在扣费 / 扣完后的 1 秒保持期 | 😣 **紧张**（`expression_22`） |
| 3 | 米饭盆满 10 秒未领取 | 😤 **傲娇**（`expression_12`） |
| 4 | 其余 | 😄 **开心**（`expression_11`） |

两条容易搞混的规则：

- **冷脸压过紧张** —— 铁锅在头上时，即使正在扣费她也保持冷脸；只有新的米饭盆掉下来才会让她重新开心。
- **紧张压过傲娇** —— 盆满 10 秒变傲娇之后，如果这时发生扣费，她会先变紧张，扣完再回到傲娇。

> 四张图**全部加载成功**才会启用表情，否则退回单张立绘。目前只有大肥鱼有表情差分。

## 💰 余额来源

只列出**你已经在 DSH 里配了 API key 的**厂商，没配的直接隐藏。

| 类型 | 厂商 | 显示 |
| --- | --- | --- |
| **金额**（6） | DeepSeek、OpenRouter、Kimi/Moonshot（CN）、Kimi/Moonshot（国际）、阶跃星辰 StepFun、Novita | `¥12.34` / `$23.50` |
| **订阅额度**（6） | 智谱 GLM Coding（国内/国际）、Kimi Coding、MiniMax Coding（国内/国际）、OpenCode Go | `剩余 63%` |

额度类各家语义不同（有的报已用、有的报剩余），统一换算成「剩余 %」后再显示。
官方确实没有余额接口的厂商不进菜单，但会把原因记进 `apiNote`，免得日后重复试错。

**自助通道**：任何没收录但确有接口的厂商，在 `.dshw-api.json` 里写一条 `provider: "custom"`
（URL + 字段路径）就能接进来，**不用改插件代码**。

## 🎉 消耗与结算

- 每轮结束弹「**喜报**」：本轮消耗 + 红闪 + 震动 + 音效 + 飘字
- 充值有**绿色光环** + 绿色飘字
- 累计计费可以随时结算成一张**全屏「喜报」证书**

计价支持**峰谷时段**（工作时段 / 非高峰 / 周末 / 法定节假日），以及自定义单价与汇率折算。

## 📅 法定节假日清单

法定节假日走谷价，所以清单能**导入**、能**快速粘贴**，而且**过期或跨年会主动提示**你更新。

## 🩺 网络自检

右键 →「网络自检…」会把**每个已配来源真打一遍**，列出通不通、取值、耗时、失败原因，
外加代理环境变量状态。

> ⚠️ Node 的 `fetch` **不会**使用 Windows 系统代理。国内直连境外接口需要在环境里同时设
> `HTTPS_PROXY` **和** `NODE_USE_ENV_PROXY=1`，否则必然静默超时。

## 📥 安装

把下面这段直接发给 DSH，它会照着装：

```
请帮我把 DSH 插件 dsh-balance-pet-extend 装好。

1. 先确定装到哪个 profile：桌面应用是 desktop，命令行 / web 界面是 web。
   先试 `dsh plugin --profile desktop list`，能正常输出就用 desktop，否则用 web。
2. 执行安装：
   dsh plugin --profile <上一步确定的 profile> add github:TsukiKenga/dsh-balance-pet-extend
3. 装完核对两处（少了插件会「装上了但完全不工作」）：
   - node_modules/dsh-balance-pet-extend/ 存在，且里面有 cordis.patch.yml
   - 该 profile 的 package.json 里，dsh.profile.bundles 包含 "dsh-balance-pet-extend"
4. 启动一次，确认日志里没有 "failed to import"。
5. 最后提醒我：需要重启 DSH 并刷新页面才会生效。

不要改动我的其它配置，也不要动 dsh-whale-widget。
```

装好后**重启 DSH + 刷新页面**，左下角会出现桌宠，右键它就能看到菜单。

本地开发用软链装（改完源码**重启即生效**，不用重装）：

```powershell
dsh plugin --profile <profile> add link:<本目录的绝对路径>
```

> ⚠️ **不要拿正在用的 `link:` 安装去测试发布包**：把 `link:` 换成 tarball 时，
> pnpm 会顺着 junction 写进源目录。要测请另建一个临时 profile。
