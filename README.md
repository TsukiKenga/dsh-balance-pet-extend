# DSH余额桌宠 · DSH Balance Pet Enhanced
>「本项目基于 [VKmich16/VK-1](https://www.github.com/VKmich16/VK-1) 二次开发」

贴在 **DSH** 页面里的余额桌宠：角色举着一块倾斜的平板，实时显示你的余额。

余额每**下降一个可配置的步长**（默认 **0.01 元**，最小也是 0.01 元，可改成 0.1、0.5、1 元），
她红闪 + 震动 + 播放打击音效，头顶飘出 `-0.10`，0.2 秒一次串成一条；
余额**上升（充值）**时，掉下一盆米饭，把它**拖到角色身上**才一次性入账。

|              |                                                              |
| ------------ | ------------------------------------------------------------ |
| **当前版本** | **v1.8.2**                                                   |
| **技术栈**   | 宿主侧 Node（余额轮询 / 计价）+ 浏览器侧单文件 IIFE（Canvas 绘制 / 交互） |
| **依赖**     | 无。只读 DSH 自己的凭据，不联网上传任何数据                  |

与 [`dsh-whale-widget`](https://github.com/MeteorNOX/DeepSeek-Balance-Whale-Widget) **互不依赖，可以共存**：
鲸鱼挂件固定在右下角，本桌宠默认吸附**左下角**。

## 💸 扣费步长：每扣多少钱提示一次

右键 →「**扣费步长（每 ¥0.01 元提示一次）**」：

- 预设 **¥0.01（1 分）/ ¥0.05 / ¥0.10 / ¥0.50 / ¥1.00**
- 「**自定义步长…**」可填 **0.01 ~ 100 元**、最小单位 **0.01 元**（两位小数）
- 改完立即生效并记住；平板显示、飘字、音效与「测试一次扣费 / 演示连续扣费」全部按新步长走

余额实际掉了 `0.30`、步长是 `0.10` 时，会**分 3 拍**各提示一次 `-0.10`；
如果只掉了不足一个步长（例如 `0.04`），最后会按**实际差额**补一拍 `-0.04`，不会漏掉也不会让显示停在半路。

## 🔊 音量调节：先选「是否分音效」

右键 →「**声音**」：最上面先选模式——

- **「分音效调节音量」勾选**：显示 6 个槽各自的「音量 / 自定义音频」；
- **取消勾选**：只显示「**全部音效音量**」（一键设置所有音效）——但**「单独音效（自定义音频）」栏仍然显示**，
  仍然可以给每个音效试听 / 上传 / 恢复出厂音频，只是子菜单里不再出现逐个音效的音量档位。

两种视图的**音量部分互斥**，勾选状态会记住；自定义音频栏两种模式下都在。6 个槽：

| 槽 | 触发时机 |
| --- | --- |
| 受击（扣费） | 每次扣费提示 |
| 投喂米饭盆 | 把米饭盆拖到她身上 |
| 铁锅扣头 | 铁锅落到头上 |
| 取下铁锅 | 双击头部取锅 |
| 回合结束喜报 | 每轮消耗气泡 |
| 结算证书 | 打开「喜报」结算页 |

> 白饭（米饭盆）掉到**窗口底部**时也会播放「铁锅扣头」这个槽的落地音；每个盆只响一次，
> 连续弹跳不会刷屏。铁锅落地仍按原有逻辑。

每个槽都能：

- 选 **0 / 25 / 50 / 75 / 100 %**，或「自定义音量…」填 0 ~ 100；
- **上传自定义音效**：文件选择器只筛 `mp3 / wav / ogg / m4a / aac / flac / webm / opus`，
  并且会再用 `Audio.canPlayType()` 复核当前 DSH 客户端 / 浏览器能否直接解码；
  选中后进入 **「截取片段」编辑器**：拖动起点 / 终点、试听选中的那一段，保存为 WAV 片段；
  也可以选择「使用完整音频」；
- **试听**（按当前音量；结算音 13.5 MB 默认不预加载）；
- **恢复出厂音效**。

自定义音频用 **IndexedDB** 存 Blob（不写进 `localStorage`，也不上传），重开页面后仍然有效。

## 📺 平板峰谷彩蛋（DSH 账户余额 / DeepSeek）

当余额来源是内置「**DSH 账户余额**」或明确是 DeepSeek 的来源时，**单击角色手里的平板**：

- 平板改成**两行**，第一行 **梁文峰**（峰价）/ **梁文谷**（谷价），第二行 **距峰时 / 距谷时 + 剩余时长**（`时:分:秒`）
- 不再有「峰谷时段」标题行；两行之外不显示余额
- 平板背景：峰价 **红色**，谷价 **绿色**
- 默认显示 **2.5 秒**后自动回到余额；时长可在右键菜单「**平板峰谷时长**」里选 1 / 2 / 2.5 / 3 / 5 / 10 秒或自定义（0.5 ~ 60 秒）

时段与计价完全同一套口径：北京时间 **9–12 / 14–18** 为峰价，其余为谷价；
周末与法定节假日全天谷价（`GET /dsh-pet/tariff.json` 由宿主计算）。
其它余额来源不会触发这个彩蛋。

## 🍚 米饭盆充值玩法

余额**上涨**时会掉下一盆米饭。这一套玩法移植自上游 VK-1 v2。

### 1. 拖动投喂

左键**按住盆拖动**，拖到角色身上才入账（碰到头发 / 头饰也算）→ 盆消失、头顶冒像素爱心、
这笔充值一次性加到屏幕上。也可以把盆**甩出去**。

拖动**有饭的米饭盆**时带**流体感形变**：位置跟手，但盆像装了半碗水一样 —— 横向拖动时**下半部分被甩在后面（剪切）**，同时**横向拉宽、竖向压扁**；停手后形变来回晃几下再回正。默认是**强（1.6×）**，右键「**拖盆流体效果**」可切 关闭 / 弱（0.7×）/ 标准（1×）/ 强（1.6×）/ 超强（2.4×），或自定义 0 ~ 2.5×。松手仍按光标速度甩出去。空铁锅不参与（要能精确扣到头上）。

> 不拖就永远不加 —— 盆可以一直躺在窗口底部。所以你想什么时候「收钱」都行。

### 2. 多盆并存

一笔充值掉一个盆，**场上可以同时有好几个**。盆彼此有**碰撞体积**，落点会错开，不会叠成一堆。

### 3. 火控雷达：目标名牌

盆被锁定时，周围会出现一个《战争雷霆》风格的**绿色方括号 + 一排读数**：

| 读数         | 含义                                                 |
| ------------ | ---------------------------------------------------- |
| **类型**     | `白饭`                                               |
| **距离**     | 盆离她多远（单位 **kpx**）                           |
| **接近率**   | 盆在靠近（正数）还是远离（负数），单位 `px/s`        |
| **相对高度** | 正数 = 盆比她高，负数 = 比它低，单位 `px`            |
| **方向环**   | 名牌下方一个圆环，环上一根指针指向盆相对她的**方位** |

> ⚠️ **米饭盆落地后 10 秒还没喂她，就会被锁定；再过 1 秒开始被吸走吃掉。**
> 如果一次充了好几笔、掉了一地盆：**只要有一个满 10 秒，所有的盆会一起被锁定、一起吸走。**

**打开火控雷达**（右键 →「打开火控雷达」）后，自动拾取会缩短到 **3 秒**：米饭盆落地稳定满 3 秒就锁定并立刻被吸走（不再额外等 1 秒），方便快速验证名牌与吸附。关掉雷达后恢复 10 秒。

### 4. 铁锅：米饭盆的「后事」

米饭盆被她**吃掉**后，会掉出一个**空铁锅**：

- 空锅先**从她身上抛到窗口底部的随机位置**，落地时播放「扣头」音效（`pot_off.mp3`）
- 想扣在头上，要把这口空锅**第二次拖回她身上**；拖着碰到她就会直接扣头
- 每吃掉一个盆掉一个锅，**头上的锅可以叠起来**（最多 5 个）；**双击她的头**只会取走**最上面**那一个并渐隐消失，下面的会自动补位
- **头上的锅是实体碰撞体积**：从上方松手掉下来的米饭盆会落在锅沿上被弹开（横向滑走），不会穿过锅落到她头上
- 扣上 / 取下时她会**竖直缩一下再弹回**（0.5 秒「回弹」形变），头上的锅与平板读数一起跟着弹
- 头上的锅大小**跟随当前尺寸档**，改尺寸后不用重新喂
- 扣头 / 取下音效已按需求对调：扣头 = `pot_off.mp3`，取下 = `pot_land.mp3`；它**永远不会**被火控雷达锁定

### 5. 左下角 / 右下角

松手吸附现在会**看她落在屏幕哪一半**：左半边吸回左下角，右半边吸回右下角。
右键「松手吸附 ▸」可以固定左侧 / 右侧 / 关闭；「吸附回…」会立刻飞回当前一侧。
**拖过屏幕中线时整只角色会镜像**（转身）：立绘、手里的平板、摸头的手一起翻到另一侧，
平板上的字仍然正向可读。
网页版仍然只能吸附**浏览器窗口**的角，不能吸附操作系统屏幕的角（这是网页形态的限制）。

## 🖐 摸头（petpet）

把指针放到她身上**来回划动**（不是点一下、也不是停着不动），累计划动 24 px 并持续 0.5 秒后，
会伸出一只手在她头顶摸一摸：手部 5 帧循环、她切到 **`expression_22`**（闭眼脸红）、头顶冒爱心。

- 摸头时整只立绘按 petpet 的原始公式做**弹性形变**（横向变宽 + 竖向压扁 + 往下沉），松开后弹回
- 任何按键（拖动 / 拿盆 / 右键菜单）都会立刻打断并短暂封锁，避免和拖拽打架
- 铁锅在头上时会先被她取下来，等锅淡出后再开始摸
- 右键「功能选择 ▸ 鼠标抚摸会开心」可以整项关闭

## 😄 表情差分

四张脸，按当前状态自动切换。优先级从高到低，**第一个命中的生效**：

| 优先级 | 条件                                   | 表情                          |
| ------ | -------------------------------------- | ----------------------------- |
| 1      | 正在摸头                               | 😣 **害羞**（`expression_22`） |
| 2      | 余额归零                               | 😤 **傲娇**（`expression_12`） |
| 3      | 铁锅扣在头上 **且** 场上没有活的米饭盆 | 😐 **冷脸**（`expression_21`） |
| 4      | 正在扣费 / 扣完后的 1 秒保持期         | 😣 **紧张**（`expression_22`） |
| 5      | 米饭盆满 10 秒未领取                   | 😤 **傲娇**（`expression_12`） |
| 6      | 其余                                   | 😄 **开心**（`expression_11`） |

两条容易搞混的规则：

- **摸头与扣费共用 `expression_22`** —— 上游 `UpdateExpression` 里摸头就是 `EXPR_NERVOUS`，
  所以她被摸时会闭眼脸红，而不是常态笑脸。
- **冷脸压过紧张** —— 铁锅在头上时，即使正在扣费她也保持冷脸；只有新的米饭盆掉下来才会让她重新开心。
  铁锅**扣上 / 取下**的瞬间还会整只弹一下（竖直回弹，0.5 秒）。
- **紧张压过傲娇** —— 盆满 10 秒变傲娇之后，如果这时发生扣费，她会先变紧张，扣完再回到傲娇。
- **摸头压过一切**（除了她自己的锅被取下的那一下）；**余额归零**则按上游 v3 的规则永远傲娇。

> 四张图**全部加载成功**才会启用表情，否则退回单张立绘。目前只有大肥鱼有表情差分。

## 💰 余额来源

内置「**DSH 账户余额**」始终在菜单里，它只读 **DSH 账号登录态** 的余额，**不会**被 API key 顶掉。
另外，如果你在凭据里配置了 `DEEPSEEK_API_KEY`，会**多出一个独立来源**「**DeepSeek（手动 Key）**」——
它只查你自己的 key，和账号余额分开缓存、分开显示、分开自检。

其余厂商只列出**已经配了 API key 的**，没配的直接隐藏。

| 类型              | 厂商                                                         | 显示                |
| ----------------- | ------------------------------------------------------------ | ------------------- |
| **账号余额**      | DSH 账户（DeepSeek 登录态）                                   | `¥12.34`            |
| **手动 Key**      | DeepSeek（`DEEPSEEK_API_KEY`；也可用 `.dshw-api.json` 的 `deepseek_apikey` 自定义 keyRef） | `¥12.34` |
| **金额**（6）     | OpenRouter、Kimi/Moonshot（CN）、Kimi/Moonshot（国际）、阶跃星辰 StepFun、Novita | `¥12.34` / `$23.50` |
| **订阅额度**（6） | 智谱 GLM Coding（国内/国际）、Kimi Coding、MiniMax Coding（国内/国际）、OpenCode Go | `剩余 63%`          |

额度类各家语义不同（有的报已用、有的报剩余），统一换算成「剩余 %」后再显示。
官方确实没有余额接口的厂商不进菜单，但会把原因记进 `apiNote`，免得日后重复试错。

**自助通道**：任何没收录但确有接口的厂商，在 `.dshw-api.json` 里写一条 `provider: "custom"`
（URL + 字段路径）就能接进来，**不用改插件代码**。

## 🎉 消耗与结算

- 每轮结束弹「**喜报**」：本轮消耗 + 红闪 + 震动 + 音效 + 飘字
- 充值有**绿色光环** + 绿色飘字
- 累计计费可以随时结算成一张**全屏「喜报」证书**
- 价格表里没有的**未收录 / 未知模型**不会丢账：仍按默认价计入金额，
  并在证书里单独标「（未收录）」+ 实际 token 用量（如 `12,345 tok`），
  末尾还有一行「未收录模型合计」；模型名为空也按「未知」记录

计价支持**峰谷时段**（工作时段 / 非高峰 / 周末 / 法定节假日），以及自定义单价与汇率折算。

### 模型价格表（手动导入 / 更新）

右键 →「**模型价格表**」：

- 「**导入价格表（JSON 文件）…**」按 `id` / `matchIds` **合并**：同一模型再导入就是**更新**，不会重复；
- 「**编辑当前价格表（JSON）…**」直接改整张表并保存（覆盖手动表）；
- 「**清空手动价格表…**」只删手动条目，内置价目表和 `.dshw-api.json` 不受影响；
- 手动表**优先于** `.dshw-api.json` 与内置价目表；保存后从**下一轮**开始按新价格计费。

格式（与 `.dshw-api.json` 的 `models[].price` 兼容，单位：**元 / 百万 token**）：

```json
{
  "models": [
    {
      "id": "mystery-model-x",
      "name": "Mystery Model X",
      "matchIds": ["mystery-model-x", "mystery-x"],
      "price": { "hit": 0.2, "miss": 1.2, "out": 6, "cur": "CNY" }
    }
  ]
}
```

`hit` = 缓存命中、`miss` = 输入、`out` = 输出；缺省字段按 0。`cur` 可以是 `CNY` 或 `USD`
（USD 再填 `rate`，按汇率折算成元）。模型名匹配用 `matchIds`（包含即命中，最长键优先），
所以无法查余额 / 未知模型也能被正确计价，结算页不再标「未收录」。

## 📥 安装

把下面这段直接发给 DSH，它会照着装：

```
请帮我把 DSH 插件 dsh-balance-pet-extend 装好。

1. 先确定装到哪个 profile：桌面应用是 desktop，命令行 / web 界面是 web。
   先试 `dsh plugin --profile desktop list`，能正常输出就用 desktop，否则用 web。
2. 执行安装：
   dsh plugin --profile <上一步确定的 profile> add github:TsukiKenga/dsh-balance-pet-extend
3. 装完核对两处（少了插件会「装上了但完全不工作」）：
   - node_modules/dsh-balance-pet-extend/ 存在，且里面有 cordis.patch.yml
   - 该 profile 的 package.json 里，dsh.profile.bundles 包含 "dsh-balance-pet-extend"
4. 启动一次，确认日志里没有 "failed to import"。
5. 最后提醒我：需要重启 DSH 并刷新页面才会生效。

不要改动我的其它配置，也不要动 dsh-whale-widget。
```

装好后**重启 DSH + 刷新页面**，左下角会出现桌宠，右键它就能看到菜单。

本地开发用软链装（改完源码**重启即生效**，不用重装）：

```powershell
dsh plugin --profile <profile> add link:<本目录的绝对路径>
```

> ⚠️ **不要拿正在用的 `link:` 安装去测试发布包**：把 `link:` 换成 tarball 时，
> pnpm 会顺着 junction 写进源目录。要测请另建一个临时 profile。
